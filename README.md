# あなたが人間であれますように

入力した言葉を次々と読み上げてくれる発声Webアプリです。  
人間が実際に話す時のように、「現在の言葉を発声しながら、次に発声する言葉を準備する」構成になっています。

## 基本的な使い方

1. 公開ページを開き、必要に応じて「読み上げ音声」や「読み上げ速度」を調整します。
2. テキストエリアに文字を入力します。確定した語句から順次読み上げられます。
3. 続けて入力すると確定した語句がキューに溜まり、前の読み上げが終わり次第、順に読み上げられます。
4. 入力内容を消したい場合は「入力済テキスト消去」、読み上げを止めたい場合は「音声停止」を押してください。

## 概要・特徴

- **途切れない会話**: 日本語入力では、確定した語句が順次キューに入り、入力を続けながら読み上げが進みます。  
   単語や文節ごとに普段どおり入力していけば、文章全体の完成を待つ事なく発話でき、会話のテンポを保てます。
- **変換不要でスピーディ**: いちいち漢字に変換する必要はありません。  
  状況によっては平仮名のまま打ち続けた方が入力も速く、会話がスムーズに進む場合があります。
- **相手の負担も軽減**: 筆談と違い、相手は文字を読み続ける必要がありません。  
  音声なら自然と耳に届くため、相手の負担を減らす事ができます。

- PC、スマートフォンでの利用が可能です。
- Android機を使用する場合は最初に「システムの言語」「アプリの言語」「テキスト読み上げの設定」「優先するエンジン」等の設定をしておくと、より自然な音声で読み上げられる場合があります。
- 読み上げ言語は基本的に「日本語」を選んでおいてください。アプリ上から一時的に切り替える事も可能です。
- 私の環境ではFirefoxを使用した際、割り当てられる音声エンジンの関係で非常に不自然な発音となりました。現状はChromeでの使用を推奨します。

> **ご利用上の注意**  
> このアプリを使っても、コミュニケーションによるストレスそのものがなくなる訳ではありません。  
> 限界を感じたら無理をせず、「もう無理です」と入力して会話を切り上げましょう。

## 開発目的

平穏を許してくれない日常の中で、説明ばかりを求められ続け、  
相手の顔を見る事さえ嫌になり、自分の声一つ出せなくなっていく。  
それでも会話を強いられる時……  
このアプリが淡々と会話をしてくれます。  
ストレスを押し殺して小声で話す必要も、  
ストレスを声にのせて相手に当たり散らす必要もありません。  
言葉と感情を切り離す事で理性を保ち、せめてもの人間らしさを維持できるようにこのアプリをつくりました。  
使わないで済むアプリなら、使わないに越した事はないと思います。  
笑顔の一つも出せなくなって、「あいつは頭がおかしい」と言われてしまえば一人で生きていくにはあまりにも残酷な世界。  
それでも見知らぬ誰かのつくった何かが、どこかで誰かを助けてくれる。  
それが明日の当たり前でありますように。  
そして、あなたの人生の最後に……  
一輪の花が咲きますように。
